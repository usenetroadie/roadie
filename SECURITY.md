# Security

roadie runs as root and handles your passwords, so security reports matter.

**Please do not open a public issue for a security problem.** Use GitHub's private
*Report a vulnerability* button on the Security tab of this repository instead.

Include what you found, how to reproduce it and which version (`roadie --version`).
You get an answer within a week. Fixes ship as a signed release; `sudo roadie update`
installs it.
