# Advanced

[← back to the README](../README.md)

## Adjust AIOStreams and Prowlarr yourself

roadie sets things up – you stay in charge.

- **AIOStreams:** open the settings page, load your configuration with UUID and config password
  (`sudo roadie access`), change what you like and save. roadie only sets languages, quality (with
  HDR), Usenet streaming, TMDB, sorting and its own addons. Updates do not write the AIOStreams
  configuration at all. *Change settings* writes only the part whose answers you changed; everything
  else stays, including your own addons.
- **Stream limit** (5 per resolution, 20 in total): *Filters → Result Limits*. roadie sets it only
  the first time.
- **Prowlarr:** open the indexer management (same login), add and test indexers under *Indexers*,
  then run `sudo roadie restart` so AIOStreams knows them. roadie deletes nothing it did not add,
  and an update never adds back an indexer you deleted.
- **Main and fallback indexers:** with more than one indexer, roadie asks which ones are your main
  indexers. AIOStreams searches those first and the fallback ones only when the main ones found
  fewer than 5 streams in your languages (other than English). roadie marks them in Prowlarr with
  the tags `roadie-main` and `roadie-fallback`; an indexer you add yourself needs one of the two.

## Your own changes

Updates (`sudo roadie update`) and *Change settings* do not undo what you changed. This is where
your changes live and what roadie does with them.

AIOStreams, Prowlarr and AIOMetadata: whatever you set on their web pages stays.

- An update does not write the AIOStreams configuration. *Change settings* writes only the part
  whose answers changed: languages, quality and sorting for the content questions, the streams for
  the indexers, the metadata for the TMDB key, the catalog addons for the catalogs.
- A roadie addon that you deleted in AIOStreams stays deleted, and one you disabled stays
  disabled, with two exceptions. The Prowlarr addon comes back when you change the indexers,
  because streams do not work without it. roadie's catalog addons (TMDB or AIOMetadata, the
  streaming services and the collections) come back when you change the TMDB key or the catalogs.
- Settings you changed inside one of roadie's addons stay too, for example the address of the
  AIOMetadata addon, a timeout or the media types. roadie remembers what it wrote last and only
  updates what is still the same.
- Groups you changed (for example a condition so that the fallback indexers only run for anime)
  and services you added yourself stay when *Change settings* writes the streams.
- Turning your own AIOMetadata on or off swaps the simple TMDB catalog addon and AIOMetadata in
  place.
- An update never adds an indexer back that you deleted in Prowlarr. Changing the indexers in
  *Change settings* does add them. An indexer you renamed is recognised by its address.
- Better filters in a later roadie version reach you through *Change settings*, not through an
  update.
- To keep posters that come through AIOMetadata fast, turn on the image cache in the AIOMetadata
  dashboard. That setting stays across updates.

Files roadie writes (they start with "Generated by roadie"): if you edited one and roadie has to
replace it, it first keeps your version next to it as `<name>.mine-YYYYMMDD.bak`, for example
`compose.yaml.mine-20261126.bak`. The copies are listed at the end of the run. Copy your edit into
one of the places below, then delete the copy.

Places roadie never touches:

- `/opt/roadie/stack/compose.override.yaml`: Docker Compose merges it into `compose.yaml`. For
  example an extra environment variable for AIOStreams:

  ```yaml
  services:
    aiostreams:
      environment:
        LOG_LEVEL: debug
  ```

  If Compose cannot read the file, roadie stops and names it. Fix it or rename it, then run the
  command again.
- `/opt/roadie/stack/config/traefik/dynamic/<your-name>.yml`: your own Traefik routes. Traefik
  reads every `.yml` file in that folder. roadie only writes `dynamic/roadie.yml`. Traefik watches
  the folder, so a change there works at once. Give your routers, services and middlewares names
  of their own: a name that `roadie.yml` already uses clashes. A broken file can stop Traefik from
  loading the routes in that folder, so if your sites disappear, look at `docker logs traefik`.
- `/opt/roadie/stack/config/authelia/own-rules.yml`: your own Authelia access rules, a YAML list.
  roadie puts them after its own rules and before the rule that protects everything else. Allowed
  policies are `bypass`, `one_factor`, `two_factor` and `deny`. Every rule needs a `domain` and a
  `policy`. A file roadie cannot use is ignored with a warning. A change to the file takes effect
  with the next `sudo roadie update` or *Change settings*. If Authelia does not start with your
  rules, roadie leaves them out with a warning and Authelia runs with roadie's rules only, until
  you change the file. For example, a site you added yourself that only asks for the password,
  without the second step:

  ```yaml
  - domain: whoami.example.duckdns.org
    policy: one_factor
  ```

  Be careful with `bypass`: it opens that path to everyone. Never open the AIOStreams settings page, Prowlarr or the status page.
- `/etc/ssh/sshd_config.d/50-own.conf`: your own SSH settings. Several `AllowUsers` lines add up,
  so this lets a second person in next to the admin user:

  ```
  AllowUsers alice
  ```
- `/etc/fail2ban/jail.local`: your own fail2ban settings.
- Your own file in `/etc/apt/apt.conf.d/`, for example `/etc/apt/apt.conf.d/99zzz-own`, for your
  own update settings. apt reads the files in alphabetical order and the last value wins, so the
  name must sort after `99zz-roadie`.

The login file `config/authelia/users.yml` is rewritten only when you change the login in roadie.
A password you changed on the login page stays. roadie's timers stay as you set them: an update
does not turn on a timer you turned off.

AIOStreams has a Jellyfin-compatible API at `/jellyfin` for Jellyfin apps and the AIOStreams desktop
app. It is reachable without the roadie login; AIOStreams asks for the configuration UUID and the
password itself. It is on by default in AIOStreams.

## Your own AIOMetadata

With a TMDB API key roadie runs its own
[AIOMetadata](https://github.com/cedya77/aiometadata): catalogs (trending, popular, top rated, by year
and language) and details in your first language, instead of the simple TMDB addon. roadie creates
its configuration once; after that it is yours. Open `https://metadata.<your address>/configure`
(same login), load the configuration with the UUID and password from `sudo roadie access`, and add
or remove catalogs, then *Save*. AIOStreams picks the change up within 15 minutes; Stremio and Nuvio
read the list of catalogs only when the addon is installed, so add your addon address once more in
the app afterwards. Posters load straight from TMDB. If you turn on rating posters (RPDB) with
the poster proxy, or the image cache, they come through `metadata.<your address>` instead. Players
can load those images without a login; the settings pages stay behind it.

You can also install AIOMetadata directly in an app, with
`https://metadata.<your address>/stremio/<uuid>/manifest.json`. That is handy for a separate
configuration per person. Only the addon routes are open; the settings pages stay behind the login.

### Own catalogs per person

When you add a person (`sudo roadie` → *People*) and your own AIOMetadata runs, roadie asks
whether they get own catalogs. Then they get their own AIOMetadata configuration: their own start
page rows and language, and changes there do not touch yours. `sudo roadie access` lists its UUID
and password, so they (or you) can load it on the metadata settings page. Removing the person
leaves that configuration unused.

## Easynews

Easynews is a Usenet service with its own fast search. Some Usenet plans include it, for example
some Newshosting deals. If you have an account, answer yes to the Easynews question (also later
under *Change settings* → Usenet). roadie then switches on AIOStreams' built-in Easynews Search,
which plays those streams straight from Easynews. With fallback indexers it runs together with the
main indexers.

## More catalogs

Catalogs are the rows on the start page of your app. roadie sets up trending, the big streaming
services and movie collections; show or hide rows under *Addons → Catalogs*. More catalog addons:

- **AIOMetadata:** many catalogs and better details (needs your own TMDB key).
- **Watchly, MyTrakt, Simkl:** rows from your own watch history.

Set the addon up on its website, copy its address (ends with `manifest.json`), load your
configuration in AIOStreams and add it under *Addons* with *Using an addon that isn't in the
Marketplace?*. roadie leaves it alone.

## Unattended setup

All answers can come from a file:

```sh
sudo roadie setup --answers answers.json      # see examples/answers.example.json
sudo roadie setup --answers answers.json --dry-run   # only check answers and server
```

For your own domain, replace the `duckdns` block with `"domain": "example.com"`.

An indexer with `"fallback": true` is a fallback indexer (see above).

`people` is optional in an answers file: without it the stored people stay; people left out of
the list are removed and their addon address stops working.

## Uninstall

`sudo roadie uninstall` removes what roadie set up: all services with their data, roadie's settings
and saved passwords, its schedules (watcher, backup, DuckDNS), its fail2ban rules, the firewall
openings for ports 80/443, the automatic restart after updates and the program itself. It asks
first and offers a last backup. The admin user, the SSH protection, your backups and Docker stay.

## Development

```sh
python3 -m unittest discover -s tests      # unit tests, standard library only
```

End-to-end tests run the whole wizard on a fresh machine: see `tests/e2e/README.md` and
`.github/workflows/e2e.yml`. A component version in `roadie/data/versions.json` is only raised
after the end-to-end run passed with it. See also [CONTRIBUTING.md](../CONTRIBUTING.md).
